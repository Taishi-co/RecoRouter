# 商城小程序上架与资金合规检查（2026-07）

> 本文是产品与技术自查清单，不替代支付机构、平台审核或律师意见。

## 已落实的资金路径

- 自营商品继续由平台自有微信商户号直接收款，不进入合作商家结算流程。
- 合作商家必须先成为微信支付平台收付通二级商户，商品才能绑定该商家。
- 用户付款时使用服务商 JSAPI 下单并标记 `profit_sharing=true`；商品款进入二级商户冻结账户，不进入平台自有账户。
- 订单履约完成后只发起一次完结分账：平台取得订单快照中的服务费，剩余货款由微信解冻给二级商户。
- 分账请求、结果查询和人工重试共用确定性单号，避免重复分账；服务费率最高 30%。
- 已分账订单退款前先按退款比例回退平台服务费，再由二级商户原路退款。
- 合作商家货款不能走平台内部提现或人工打款；不同商家的商品当前必须分开结算。

官方产品模型：[平台收付通产品介绍](https://pay.wechatpay.cn/doc/v3/partner/4012086891)、[请求分账](https://pay.wechatpay.cn/doc/v3/partner/4012691594)。

## 上线前必须完成的外部配置

1. 平台主体开通微信支付平台收付通，合作商家完成二级商户进件和开户意愿确认。
2. 生产环境配置平台商户号、商户证书序列号、商户私钥、API v3 密钥、微信支付公钥及公钥 ID、平台主体全称和支付回调地址。
3. 在管理端录入合作商家营业执照、微信二级商户号、审核状态和每家签约服务费；只有资质审核通过后才能启用。
4. 使用真实二级商户完成 1 分钱以上、能产生至少 1 分钱服务费的支付、履约、分账、分账查询、全额退款和部分退款联调。
5. 平台与商家签署平台服务协议，明确服务费、退款、售后、税务、保证金（如有）和退出机制；保存商家核验档案并定期复核。

## 当前仍会阻断上架或正式运营的事项

### P0：发布前必须处理

- **用户接口鉴权不足**：部分商城接口仍直接信任请求中的 `userId`，没有统一校验 Bearer token 与资源所有者。必须加商城用户鉴权和对象级权限校验，避免越权查看订单、地址、客服和售后信息。
- **账号注销缺失**：商城没有有效的账号注销、个人信息删除/匿名化与处理进度入口。
- **隐私规则缺失**：设置页只有说明文字，没有可阅读的隐私政策、第三方 SDK 清单、个人信息收集清单、撤回同意和投诉渠道；首次运行也没有明确确认流程。
- **交易发货信息未同步微信**：代码中未发现微信小程序交易订单发货信息上传链路，需要按当前类目和微信公众平台要求接入并完成测试。
- **经营主体与许可公示不完整**：合作商品已显示销售主体和营业执照，但平台自身营业执照、平台服务协议/交易规则、食品经营许可或仅销售预包装食品备案，以及商家对应行政许可仍需在首页或经营主页持续公示。
- **资质材料尚未实质核验**：后台目前记录营业执照地址和审核状态，但实质审查、有效期复核、食品许可核验、变更报送和违规商家处置仍需形成运营制度与留痕。

### P1：建议随首次正式版本完成

- 正式电子发票申请和开票状态闭环；当前“发票申请”只是进入客服会话。
- 微信支付消费者投诉 2.0 的通知、处理和时限监控。
- 对微信支付 API 成功响应做统一验签；支付通知在配置微信公钥后已经验签，合作商家启用也会被配置闸门阻止。
- 平台服务协议、交易规则的版本留存、修改公示和商家退出流程。
- 订单、商家、资质、投诉和交易记录的法定期限归档与导出。

## 主要法规依据

- [《非银行支付机构监督管理条例》](https://www.pbc.gov.cn/tiaofasi/144941/144953/5174993/index.html)：未经批准不得从事或变相从事支付业务。
- [中国人民银行关于电商平台资金结算规则的答复](https://www.pbc.gov.cn/zhengwugongkai/4081330/4081344/4081419/4081727/2025080819055125759/2020022716130667785.pdf)：平台先归集资金、再向商户结算属于重点整治风险模式。
- [《中华人民共和国电子商务法》](https://www.samr.gov.cn/wljys/gzzd/art/2023/art_3e75434c954b4cb9bd14867dacff26d1.html)：主体和行政许可公示、商家核验登记、平台协议及交易规则公示。
- [《网络食品销售经营者落实食品安全主体责任监督管理规定》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2026/art_9adba18c25a84f24a6334c4c20b61e2f.html)：网络食品平台对许可证或备案材料进行实质审查并监督公示。
- [《App违法违规收集使用个人信息行为认定方法》](https://www.cac.gov.cn/2019-12/27/c_1578986455686625.htm)：提供个人信息更正、删除、账号注销和投诉举报渠道。
